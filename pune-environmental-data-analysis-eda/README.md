# 🌍 Pune Smart City – Environmental Data Analysis (EDA)

## 📌 Project Overview
This project was developed during the **EDAthOn – Green Pune** organized by Innomatics Research Labs.  
The objective of this project is to perform Exploratory Data Analysis (EDA) on the Pune Smart City Environmental Sensor Dataset (2019) and convert raw environmental data into meaningful insights using data analysis and visualization techniques.

---

## 📊 Dataset Information
- Dataset: Pune Smart City Environmental Sensor Dataset (2019)
- Total Records: 103,205
- Total Features: 28
- Data Type: Time-series and location-based sensor data

### Environmental Parameters
- Air Pollutants: PM2.5, PM10, NO2, CO, SO2, Ozone
- Environmental Factors: Temperature, Humidity, Sound, Light, Air Pressure
- Time Features: Timestamp, Hour, Day, Weekday
- Location Data: Latitude, Longitude, Sensor Location Name

8. Insight Generation

---

## 📈 Key Insights
- Identified relationships between pollution levels and environmental parameters.
- Detected abnormal environmental readings using outlier detection techniques.
- Analyzed pollution patterns across different locations and time intervals.
- Observed variation in environmental conditions over different hours and days.
- Built interactive Power BI dashboard for pollution and environmental monitoring.

## 📊 Results
This project successfully demonstrated how Exploratory Data Analysis (EDA) and Data Visualization techniques can transform raw environmental sensor data into meaningful insights for environmental monitoring and data-driven decision making.
