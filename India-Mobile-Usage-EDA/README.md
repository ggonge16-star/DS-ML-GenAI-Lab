This project analyzes mobile phone usage patterns in India using Python (Pandas, Matplotlib, Seaborn) for Exploratory Data Analysis (EDA) and Power BI for interactive data visualization.

The goal of this project is to identify user behavior, recharge spending patterns, screen time habits, and mobile dependency across different age groups and usage types.

📊 Key Analysis Performed

Data Cleaning & Preprocessing

Missing Values Handling

Outlier Detection using Boxplots

Correlation Analysis

User Behavior Analysis

Main insights explored:

Age + OS + Phone Brand combination with highest recharge cost

Relationship between Screen Time, Data Usage, and Recharge Spend

Top 10% users contribution to total recharge revenue (Pareto Analysis)

Whether Gaming users spend more on recharge

Identification of Power Users

Mobile dependency based on Primary Phone Usage

Age Group vs Screen Time vs Data Usage vs Recharge Spend
