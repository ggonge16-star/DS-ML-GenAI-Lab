# 🚀 Heart Disease Prediction System (Machine Learning Project)

## 🧠 Problem Statement
Cardiovascular diseases are one of the leading causes of death worldwide. Early detection is critical but challenging. This project aims to build a machine learning model that predicts the risk of heart disease using medical and lifestyle data.

---

## 🎯 Objective
To develop an accurate and reliable machine learning model that can predict whether a person is likely to have heart disease.

---

## 📊 Features Used
- Age  
- Blood Pressure  
- Cholesterol Level  
- Diabetes  
- Smoking  
- BMI  
- Exercise Habits  
- Family Heart Disease  

---

## ⚙️ Workflow

### 1. Data Preprocessing
- Handled missing values  
- Removed irrelevant and redundant features  

### 2. Feature Engineering
- Ordinal Encoding (for ordered categories)  
- One-Hot Encoding (for unordered categories)  

### 3. Handling Imbalanced Data
- Applied SMOTE to balance the dataset  

### 4. Model Building
- Random Forest  
- Decision Tree  
- SVM  
- Naive Bayes  
- KNN  
- Logistic Regression  

### 5. Model Evaluation
- Accuracy  
- Precision  
- Recall  
- F1-score  

---

## 📊 Key Insights
- Blood Pressure, Cholesterol, and Diabetes are major risk factors  
- Lifestyle factors like BMI and Exercise also impact heart disease  
- SMOTE improved minority class prediction  

---

## 🏆 Best Model
Random Forest performed the best due to its ability to handle complex data and provide balanced performance.

---
