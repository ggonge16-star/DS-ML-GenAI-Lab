# Customer Churn Prediction Using ANN

## 📌 Project Overview

This project predicts customer churn using an Artificial Neural Network (ANN).  
The model analyzes customer-related features and predicts whether a customer is likely to leave the company or not.

The project includes:

- Data Preprocessing
- Feature Encoding
- Feature Scaling
- ANN Model Building
- Dropout Regularization
- Batch Normalization
- Early Stopping
- Model Evaluation
